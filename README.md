# 교실 그랑프리

학생 수만큼 자동차가 3D 트랙을 달리고, 들어온 순서대로 발표 순서를 정하는 교실용 랜덤 추첨 앱입니다. 인터넷 없이도 실행됩니다.

## 설치 파일 받기

안드로이드 기기(휴대폰, 태블릿, 전자칠판)의 브라우저에서 아래 주소를 열면 최신 설치 파일이 내려받아집니다.

**https://github.com/pyoyo1206/classroom-grandprix/releases/latest/download/ClassroomGrandPrix.apk**

## 설치하기

1. 내려받은 `ClassroomGrandPrix.apk` 를 엽니다.
2. "출처를 알 수 없는 앱" 경고가 나오면 **설정**을 눌러 이 브라우저(또는 파일 관리자)에서 설치를 허용합니다.
3. **설치**를 누릅니다. Play 프로텍트 안내가 나오면 **무시하고 설치**(또는 "세부정보 → 설치")를 선택합니다.

새 버전도 같은 주소에서 받아 그대로 설치하면 기존 앱 위에 덮어써집니다. 입력해 둔 제목과 이름은 유지됩니다.

## 앱 사용 팁

- 화면은 가로, 전체화면으로 열리고 경주 중에는 화면이 꺼지지 않습니다.
- 경주 중이나 결과 화면에서 **뒤로 가기**를 누르면 설정 화면으로 돌아갑니다. 설정 화면에서 누르면 앱이 닫힙니다.
- 제목, 이름, 결석 표시는 기기에 저장되어 다음에 열어도 남아 있습니다.

## 고치는 방법

`app/src/main/assets/www/index.html` 이 경주 화면입니다. 이 저장소의 `main` 브랜치에 변경이 올라가면 GitHub Actions가 새 APK를 자동으로 만들어 Releases에 올립니다 (약 3~5분).
